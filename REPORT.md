# Usability Testing Report

Product: Oveelo Shopping Website

Number of Test Scenarios: 4

Tasks Performed:
1. Browse Homepage
2. Search Product
3. View Product Details
4. Add Product to Cart

Observations:
- Navigation is simple and intuitive.
- Product categories are clearly displayed.
- Visual design is attractive.
- Shopping flow is easy to understand.

Recommendations:
- Improve search visibility.
- Add advanced filters.
- Enhance page loading speed.

Outcome:
The website demonstrates good usability and provides a positive shopping experience.
